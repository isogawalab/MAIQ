# MAIQ - Project Page

This repository contains the static project page for:

**MAIQ: Mask-Aware No-Reference Image Quality Assessment for Inpainting** (WACV 2027)

Yota Koshimoto, Taiki Uchiyama, Mariko Isogawa (Keio University)

## Local Preview

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

For GitHub Pages, enable Pages in the repository settings and deploy from the `main` branch root.
